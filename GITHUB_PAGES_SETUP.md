# Publish Colt Williames Portfolio on GitHub Pages

This package contains the portfolio website prepared for hosting in the existing repository:

https://github.com/williamesc31/Portfolio

The `docs/` folder contains the website. No ChatGPT hosting or account is required to view the website after it is published through GitHub Pages.

## Upload

1. Extract this ZIP on your computer.
2. Open the Portfolio repository on GitHub and select the branch you want to publish (usually `main`).
3. Choose **Add file > Upload files** and upload the extracted `docs` folder, preserving its contents and subfolders. Upload the extracted files, not the ZIP itself.
4. Confirm the website's entry file appears as `docs/index.html` in the repository. It must not be nested inside another package folder.
5. Commit the uploaded files. Existing project notebooks and the repository README can remain where they are. Review any existing files with the same paths before replacing them.

## Enable GitHub Pages

1. Open the repository's **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing the uploaded website and select **/docs** as its source folder.
4. Click **Save**.
5. Wait for the Pages deployment to complete. In Settings > Pages, click **Visit site** and copy the address shown by GitHub.

The standard expected address for this repository is `https://williamesc31.github.io/Portfolio/`. This address is an expectation, not confirmation of a live deployment. The URL displayed by GitHub Pages after deployment is authoritative; a custom domain or account settings can change it.

## Submission checks

- The website opens while signed out of GitHub.
- About, Projects, and Contact navigation works.
- The About section is fully populated.
- Project details open, README downloads work, and repository links point to the Portfolio repository.
- The repository is accessible to the instructor.

Submit the published GitHub Pages website URL in Blackboard, along with the repository URL if requested. This package is the website source; uploading this ZIP to Blackboard alone does not publish the website.

## Included content

The website includes seven project summaries, three clearly marked project placeholders, two featured case studies, two draft README downloads, a complete About section, and a Contact shell with the supplied GitHub link. Email and other professional links can be added later.
